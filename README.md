# NERO OS

A standalone, browser-based desktop experience inspired by Windows 11 and branded for NERO.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server.

## Included in the first preview
- Responsive desktop and taskbar with live clock
- Start menu with app search
- Draggable, resizable, maximizable, and minimizable windows
- File Explorer, NERO Browser preview, Notepad, Calculator, Photos, Settings, and About
- Desktop context menu and accent color settings

## Status
Early preview (0.1.0). This is a web desktop shell, not a replacement for a computer's operating system. File access, real web navigation, accounts, and persistent settings are not connected yet.
